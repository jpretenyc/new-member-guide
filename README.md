# Nourished by the Good Word

A resource guide for new members of The Church of Jesus Christ of Latter-day Saints: key scripture passages, Church movies and videos, general conference talks, books, apps, and history sites, with Ordinances & Temple and Church Basics on separate tabs.

Prepared by Church members. Not an official publication of the Church.

- `index.html` — the website (single self-contained page)
- `nourished-guide.pdf` — printable version
